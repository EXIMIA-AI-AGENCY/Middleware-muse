              Probando las claves de Kraken, la firma y el proxy.

                Configurar Kraken (una sola vez)

                  1. Crea una API key en Kraken, solo para Muse

                    Kraken → tu perfil → Settings → API → Create API key. Ponle de nombre «Muse».

                    • Query Funds
                    • Query Open Orders & Trades
                    • Query Closed Orders & Trades
                    • Query Ledger Entries
                    • Withdraw Funds, Deposit, Earn, Create & Modify Orders, Cancel/Close Orders: desmarcados

                    En Advanced, pon Nonce Window = 10000. Deja la lista de IPs vacía (Vercel no tiene una IP fija). Kraken muestra la Private key una sola vez: tenla a mano para el paso 2.

                  2. Pégalas en Vercel (nunca en un chat)

                    Vercel → proyecto ghl-proxy-muse → Settings → Environment Variables. Añade dos variables, en Production y marcadas como Sensitive:

                    KRAKEN_API_KEY
                    la API key de Kraken
                    KRAKEN_API_SECRET
                    la Private key de Kraken

                  3. Haz Redeploy y vuelve aquí

                    Vercel → Deployments → el último → ⋯ → Redeploy. Al terminar, pulsa Verificar ahora: el panel unirá tus dos claves en una sola llave para Muse. GoHighLevel no se toca.

                          Probando la clave de Stripe, sus permisos y el proxy.

                            Configurar Stripe (una sola vez)

                              1. Crea una clave restringida en Stripe, solo para Muse

                                Stripe → Developers → API keys → Create restricted key. Nombre: «Muse». Pon todos los recursos en Write (o en Read los que Muse solo deba leer). Si Stripe te ofrece «Authorizing agent access to your account», elígelo: añade aprobaciones de Stripe para reembolsos y cancelaciones.

                                Una clave nueva y restringida se puede revocar sin afectar a lo que ya usa tu clave principal (GoHighLevel, otras apps). No uses restricciones por IP: Vercel no tiene IP fija. Stripe muestra la clave (rk_live_…) una sola vez.

                              2. Pégala en Vercel (nunca en un chat)

                                Vercel → proyecto ghl-proxy-muse → Settings → Environment Variables. Añade una variable en Production, marcada como Sensitive:

                                STRIPE_SECRET_KEY
                                la clave rk_live_… (o rk_test_… para probar sin dinero real)

                              3. Haz Redeploy y vuelve aquí

                                Vercel → Deployments → el último → ⋯ → Redeploy. Al terminar, pulsa Verificar ahora: el panel creará una llave nueva solo para Stripe. GHL y Kraken no se tocan.

                              Qué puede hacer Muse

                              • Clientes, pagos, cobros, reembolsos, facturas, suscripciones, productos, precios, cupones, Checkout y Payment Links (te pedirá confirmación antes de cobrar, devolver o escribir a clientes)
