      Verificando…

      Probando las claves de Kraken, la firma y el proxy.

        Configurar Kraken (una sola vez)

          1. Crea una API key en Kraken, solo para Muse

            Kraken → tu perfil → Settings → API → Create API key. Ponle de nombre «Muse».

            • Query Funds
            • Query Open Orders & Trades
            • Query Closed Orders & Trades
            • Query Ledger Entries
            • Withdraw Funds, Deposit, Earn, Create & Modify Orders, Cancel/Close Orders: desmarcados

            En Advanced, pon Nonce Window = 10000. Deja la lista de IPs vacía (Vercel no tiene una IP fija). Kraken muestra la Private key una sola vez: tenla a mano para el paso 2.

          2. Pégalas en Vercel (nunca en un chat)

            Vercel → proyecto ghl-proxy-muse → Settings → Environment Variables. Añade dos variables, en Production y marcadas como Sensitive:

            KRAKEN_API_KEY
            la API key de Kraken
            KRAKEN_API_SECRET
            la Private key de Kraken

          3. Haz Redeploy y vuelve aquí

            Vercel → Deployments → el último → ⋯ → Redeploy. Al terminar, pulsa Verificar ahora: el panel unirá tus dos claves en una sola llave para Muse. GoHighLevel no se toca.

          Qué puede hacer Muse

            Bloqueados siempre, en cualquier configuración

              Permisos de la llave de Kraken

              Lo que Kraken permite a esta llave. Se cambian en Kraken → Settings → API, sin tocar Vercel.

                  Cambiar las claves de Kraken
                  1. Crea una API key nueva en Kraken (mismos permisos y Nonce Window 10000) y borra la anterior.
                  2. En Vercel, reemplaza KRAKEN_API_KEY y KRAKEN_API_SECRET y haz Redeploy.
                  3. La llave de Muse cambia sola: cópiala otra vez aquí y dásela a Muse en su tarjeta segura.
